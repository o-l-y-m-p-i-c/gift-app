# Бесплатные сервисы для хостинга Gift Threshold App

## Сравнение бесплатных тарифов (2026)

### 1. Render — лучший для старта

| Параметр | Free план |
|---|---|
| Цена | $0/мес |
| Web service | 512 MB RAM, 0.1 CPU |
| PostgreSQL | 1 GB, удаляется через 30 дней |
| Sleep | Засыпает через 15 мин без трафика |
| Пробуждение | ~1 минута |
| Лимит часов | 750 часов/мес на workspace |
| Кредитная карта | Не требуется |
| Коммерческое использование | ✅ Разрешено |

**Плюсы:**
- Не нужна кредитная карта
- Коммерческое использование разрешено
- Поддержка Docker (есть Dockerfile в Shopify template)
- 750 часов хватает для 1 сервиса 24/7

**Минусы:**
- База данных удаляется через 30 дней (нужно мигрировать на платный $6/мес)
- Засыпает без трафика (~1 мин на пробуждение)
- Нет бэкапов БД на бесплатном тарифе

**Подходит для:** разработки и тестирования. Для продакшена — $7/мес (Starter).

---

### 2. Railway — $1/мес бесплатно

| Параметр | Free план |
|---|---|
| Цена | $0/мес |
| Кредит | $1/мес (не переносится) |
| Trial | $5 одноразово на 30 дней |
| RAM | 512 MB |
| CPU | 1 vCPU |
| Volume storage | 0.5 GB |
| Кредитная карта | Не требуется для trial |

**Плюсы:**
- Простой деплой из GitHub
- $1/мес хватает для маленького приложения
- PostgreSQL встроенный

**Минусы:**
- $1/мес — этого мало для постоянно работающего приложения
- Node.js сервис 24/7 = ~$2.40/мес только за RAM
- Нужен Hobby план ($5/мес) для реального продакшена

**Подходит для:** первых 30 дней (trial $5), потом нужен Hobby ($5/мес).

---

### 3. Vercel — НЕ подходит для Shopify приложений

| Параметр | Hobby план |
|---|---|
| Цена | $0/мес |
| Коммерческое использование | ❌ Запрещено |
| Function timeout | 10 сек (макс 60 сек) |
| CPU | 4 часа/мес |
| Deployments | 100/день |

**Почему НЕ подходит:**
- **Коммерческое использование запрещено** — Shopify app = коммерческий проект
- Function timeout 10 сек — Shopify требует ответа за 2 секунды
- Нет persistent storage (нужна внешняя БД)
- Vercel может заблокировать аккаунт за нарушение fair-use

**Вердикт:** ❌ Не использовать для Shopify приложений.

---

### 4. Fly.io — был хорош,但现在 нет free tier

| Параметр | Trial | Free (старые аккаунты) |
|---|---|---|
| Цена | $0 (7 дней) | $0 (только для аккаунтов до окт 2024) |
| VM hours | 2 часа всего | 2160 часов/мес |
| IPv4 | $2/мес | $2/мес |
| Кредитная карта | Не требуется для trial | Требуется |

**Почему НЕ подходит:**
- Free trial = 2 часа VM или 7 дней (что быстрее)
- Нет free tier для новых аккаунтов (после окт 2024)
- IPv4 стоит $2/мес дополнительно
- Egress $0.02/GB без free allowance

**Вердикт:** ❌ Только если аккаунт создан до октября 2024.

---

### 5. Firebase (create-shopify-firebase-app) — $0 до масштаба

| Параметр | Free план (Spark) |
|---|---|
| Цена | $0/мес |
| Cloud Functions | 2M вызовов/мес |
| Firestore | 1 GB хранение, 50K чтений/день |
| Hosting | 10 GB transfer, 0.5 GB storage |
| Кредитная карта | Не требуется |

**Важно:** Cloud Functions требуют **Blaze план** (платный), но с generous free tier:
- 2M вызовов/мес бесплатно
- $5/мес при 50,000 установленных магазинов

**Плюсы:**
- $0/мес до реального трафика
- Serverless — не засыпает
- Firestore — NoSQL, не удаляется через 30 дней
- Специальный шаблон для Shopify: `npx create-shopify-firebase-app`

**Минусы:**
- Нужна кредитная карта для Blaze плана
- NoSQL вместо SQL (не Prisma-совместимо)
- Другая архитектура (не Remix)

**Подходит для:** если готов использовать Firebase вместо Remix + Prisma.

---

### 6. Supabase — бесплатная PostgreSQL база

| Параметр | Free план |
|---|---|
| Цена | $0/мес |
| PostgreSQL | 500 MB |
| Egress | 5 GB/мес |
| Auth | 50,000 MAU |
| Edge Functions | 500,000 вызовов/мес |
| Pausing | После 7 дней неактивности |
| Проектов | 2 бесплатных |

**Плюсы:**
- Настоящий PostgreSQL (совместим с Prisma)
- 500 MB — достаточно для нашего приложения
- Не удаляется через 30 дней (как Render)
- Бэкапы: нет автоматических, но можно делать вручную

**Минусы:**
- Засыпает через 7 дней без активности
- Нет автоматических бэкапов
- 500 MB лимит на БД

**Подходит для:** БД только. Хостинг приложения — отдельно.

---

### 7. Cloudflare Workers — serverless альтернатива

| Параметр | Free план |
|---|---|
| Цена | $0/мес |
| Requests | 100,000/день |
| CPU time | 10 ms/request |
| Memory | 128 MB |
| D1 (SQLite) | 5 GB, 5M reads/день |
| KV | 1 GB storage, 100K reads/день |

**Плюсы:**
- 100K запросов/день — много для маленького приложения
- D1 (SQLite) — 5 GB бесплатно
- Не засыпает (serverless)
- Edge сеть (быстро везде)

**Минусы:**
- 10 ms CPU на запрос — очень мало
- Не подходит для Remix (нужен адаптер)
- Сложная архитектура для Shopify app

**Подходит для:** API endpoints, не для полноценного Remix приложения.
